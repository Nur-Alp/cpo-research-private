# Analyst-estimate model workspace

The [12 August baseline reconciliation audit](analyst-baseline-reconciliation-audit-2026-08-12.md)
is the current control record. `ANL-002` is a provisional consolidated-scale
snapshot; it is not a CPO consensus or an earnings forecast.

This folder contains only derived private modelling artifacts. It receives traceable inputs from [the analyst-estimate register](../analyst-estimate-register.md) and should never contain copied report pages or screenshots.

The [estimates-to-variant reconciliation](estimates-to-variant-reconciliation-2026-08-12.md)
is the controlling audit for separating observed facts, external expectations,
Nur Alpys assumptions and variant conclusions.

Use the model in this order:

1. Reconcile each company’s baseline consensus.
2. Define CPO-specific bear/base/bull drivers independently of baseline consensus.
3. Calculate incremental revenue, gross profit, operating profit, EPS and valuation sensitivity.
4. Compare the model result with market expectations and write a falsifiable variant view.

See [scenario-model specification](scenario-model-specification.md) and [quarterly refresh checklist](quarterly-refresh-checklist.md).
