# Quarterly analyst-estimate refresh checklist

1. Set the report and market-data as-of date.
2. Add new restricted source records and retain prior versions.
3. Reconcile fiscal year, GAAP/non-GAAP basis, currency, stock splits and TSMC ADR/share conversion.
4. Flag estimates older than 90 days; preserve but exclude from current ranges unless explicitly retained.
5. Compare prior-quarter consensus/variant inputs against reported company results.
6. Update each company’s CPO scenario only where a source or explicit assumption changed.
7. Run input-completeness, unit, sign, double-count and scenario-probability checks.
8. Confirm every active estimate row has its `EST-###`, `ANL-###`, as-of date, fiscal period, unit, accounting basis, report location and public-use status.
9. Confirm any public draft uses only derived ranges permitted by the source licence; it must not reproduce analyst tables, report pages, named-analyst figures or proprietary consensus detail.
10. Keep the earnings/valuation output as `not eligible` unless the company-specific CPO numerator, product-margin sensitivity, tax, diluted shares and accounting-basis reconciliation all clear their gates.
11. Update catalysts, disconfirming evidence and public derived ranges.
12. Record all changed, delayed or withdrawn conclusions in the public change log.

Use the [quarterly evidence-change register](../../09-primary-research/quarterly-evidence-change-register-2026-08-12.md)
for the private pre-publication record. If no matched evidence changes a gate,
record **unchanged** rather than inferring progress from silence or repetition.

Use the [expectations-versus-variant quarterly handoff](expectations-variant-quarterly-handoff-2026-08-13.md)
to keep reported outcomes, external expectations, CPO commercial gates and
variant conclusions on separate dated records.
