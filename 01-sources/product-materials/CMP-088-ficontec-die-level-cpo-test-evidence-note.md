# CMP-088 — ficonTEC die-level CPO engine test capability

- **Canonical source:** https://www.ficontec.com/jp/multi-site-die-level-tester-for-double-sided-compact-3d-cpo-optical-engines/
- **Publisher:** ficonTEC
- **Published:** 2025
- **Reviewed:** 2026-08-13
- **Source class:** Supplier product announcement / test capability

## Bounded extraction

ficonTEC describes its DLT-D1 as a multi-site, die-level test system for
double-sided compact 3D CPO optical engines. It describes automated fibre
coupling for devices with attached receptacles, JEDEC tray handling, up to three
parallel test heads, and a wafer-to-die test portfolio on a common data
framework.

## Permitted use

This establishes that a die-level test insertion between wafer test and final
package/module test is commercially available as equipment capability, with
specific relevance to OSAT workflows.

## Not permitted

It does not identify a customer, installed production line, engine SKU, test
time, coverage, yield, escape/rework, output, cost, revenue or margin.
