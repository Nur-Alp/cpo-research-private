# PRI-002 — Lightmatter detachable FAU patent application

- **Canonical record:** https://patents.google.com/patent/WO2025145204A1/en
- **Publication:** WO2025145204A1, *Fiber array unit assembly and co-packaged optics using the same*
- **Public record publication date:** 2025
- **Reviewed:** 2026-08-13
- **Source class:** Public patent application / architecture disclosure

## Bounded extraction

The disclosed architecture separates a detachable FAU/lens subassembly from a
subassembly fixed to the PIC. It describes kinematic adjustment, pin/socket or
fiducial mating features and optical elements distributed across the two
subassemblies.

## Permitted use

It shows an explicit route by which a fibre-array unit can be removable while
the PIC-side optical structure remains fixed. It is useful for distinguishing
replaceable fibre-interface scope from replaceable engine/package scope.

## Not permitted

The filing does not prove the product is shipped, production-qualified, lower
scrap, field-serviceable at fleet scale, or economically advantageous. It is
not a supplier-share or value-capture record.
