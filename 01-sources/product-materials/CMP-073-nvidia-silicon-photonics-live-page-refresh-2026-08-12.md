# CMP-073 — NVIDIA silicon-photonics live-page refresh

- **Publisher:** NVIDIA
- **Canonical source:** https://www.nvidia.com/en-us/networking/products/silicon-photonics/
- **Page reviewed:** 2026-08-12
- **Evidence class:** Current product/adopter-page refresh; not an acceptance or shipment record

The live NVIDIA silicon-photonics page describes Spectrum-X Ethernet Photonics
as a 200G-SerDes CPO architecture and lists CoreWeave, Lambda, Meta, Microsoft
and Oracle Cloud Infrastructure as first adopters. It separately describes the
Spectrum-X product as available in the second half of 2026 and names a broad
technology-partner set.

**Evidence boundary:** The page does not identify which adopter accepted
`SN6800`/`SN6810` or the corresponding `-LD` ordering-family label. It provides
no acceptance date, units, ports, repeat shipment, field-service population,
supplier allocation, yield, ASP or margin.

**Decision treatment:** This is a current named-adopter ecosystem refresh and
a stronger follow-up lead for Microsoft and the other named operators. It does
not create an exact-SKU customer numerator or change the commercial-proof gate.
