# Viewing Retained Web Sources

**Purpose:** readable companion PDFs for the web sources retained in this repository.

## How to use these files

- Open the `*-web-archive.pdf` file when you want a readable local copy in VS Code, Preview, or Finder.
- Use the **canonical original** link below when citing, sharing, or checking the source at the publisher's site.
- The matching `.html` file remains the raw preservation copy. It is intentionally retained for searchable source text, but it is not the convenient reading format.
- A snapshot preserves what was retrievable on **2026-08-07**. It is not a publisher-issued PDF, and it does not replace the original webpage.

## Citation rule

In research notes, cite the **canonical original webpage** (not the local rendered snapshot) and include the source ID. Use the snapshot only as a convenient, locally retained reading copy. Example:

> Lumentum, *Lumentum Announces Second Quarter Fiscal 2026 Financial Results*, 3 February 2026, `CMP-010`, [original webpage](https://investor.lumentum.com/financial-news-releases/news-details/2026/Lumentum-Announces-Second-Quarter-of-Fiscal-Year-2026-Financial-Results/default.aspx); local readable snapshot retained.
