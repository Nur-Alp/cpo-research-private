# Restricted estimate intake template

Use one copy of this template for each metric or coherent metric set before it
enters a private scenario model. This is a control record, not a copy of the
analyst report. Preserve the original licensed source locally under the
ignored `ANL-###` filename; do not paste report pages, tables or screenshots
into this file.
