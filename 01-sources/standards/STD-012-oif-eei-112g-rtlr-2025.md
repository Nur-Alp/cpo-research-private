# STD-012 — OIF EEI-112G-RTLR implementation agreement

Canonical PDF: <https://www.oiforum.com/wp-content/uploads/OIF-EEI-112G-RTLR-01.0.pdf>

Reviewed 2026-08-07. OIF-EEI-112G-RTLR-01.0 (October 1, 2025) defines a retimed-transmitter/linear-receiver chip-to-module interface over 36–56 GSym/s PAM4, including the 53.125 GSym/s Ethernet rate. The agreement supports short and long host-interface modes, 1–n lanes, hot plug, and listed 100G/200G/400G/800G Ethernet PMDs. It specifies a minimum 200 mm host PCB trace plus one connector and 20 mm module trace, a recommended 16 dB ball-to-ball insertion-loss boundary with 11.9 dB allocated to host PCB/cable losses, and raw BER/FEC/FLR requirements.

Evidence boundary: this is an OIF implementation agreement, not a shipment, power, yield, field-reliability or cost study. It establishes a concrete interoperable retimed/linear alternative and its test boundary; it does not prove that every 200G/lane deployment can meet the boundary or that RTLR beats CPO on total cost.
